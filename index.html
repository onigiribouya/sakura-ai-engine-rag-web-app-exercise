RAG Q&A App

Sakura AI Engine answers your question
by referencing the registered documents.

This app sends what you type on the Web screen to Flask,
and Flask calls the Sakura AI Engine API.

RAG Parameters

Specifies how many of the top, most relevant chunks to retrieve for the question.
A larger value references more chunks.

Current value: 0.3

Specifies the threshold used when searching documents.

Fixed Settings (Cannot Be Changed)

  • Search model: multilingual-e5-large
  • Answer-generation model: gpt-oss-120b
  • Distance metric: cosine
